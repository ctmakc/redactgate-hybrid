        How the hatch works
        
    
          
      
        1. 01
          Find, on the device
          Checksum-verified patterns catch SINs, cards, health numbers and IBANs. Gemini Nano, through Firebase AI Logic in ONLY_ON_DEVICE mode with a JSON schema, finds names, organizations and addresses. If Nano is missing, the patterns still run and the cloud never stands in for it.
          2. 
      
        2. 02
          Swap for tokens
          Each value gets a stable token like [[PERSON_1]]. The table of real values lives in this tab’s memory and is gone on reload.
          3. 
      
        3. 03
          Check before the door opens
          The guard re-scans the outgoing text for every real value and every pattern. One hit keeps the cloud door shut.
          4. 
      
        4. 04
          Ask the cloud with tokens
          Firebase AI Logic in ONLY_IN_CLOUD mode sends the tokenized text to Gemini. Each answer shows its inferenceSource.
          5. 
      
        5. 05
          Fill in, on the device
          Tokens in the answer are replaced with the real values here. Tokens the model made up are flagged, and the run goes to the log.
          6. 
    
        
    
        Built on RedactGate, our earlier server-side redaction gateway. This version is new: the detection runs in the browser with Gemini Nano, and the cloud step goes through Firebase AI Logic.
